## 통화 계산 원칙

- 종목의 실제 거래 가격은 해당 시장 통화로 저장한다.
- 포트폴리오는 사용자가 `₩ KRW` 또는 `$ USD` 기준으로 선택해 본다.
- **매입원가 = 거래 당시 환율**
- **현재 평가액 = 현재 환율**
- 따라서 환차익·환차손까지 선택한 표시 통화 기준 손익에 포함된다.

예: 삼성전자를 ₩1,000,000에 샀을 때 `$1 = ₩1,250`이면 달러 매입원가는 $800. 나중에 평가액이 ₩1,100,000이어도 환율이 `$1 = ₩1,400`이면 달러 현재가치는 약 $785.71이므로 원화로는 수익, 달러로는 손실일 수 있다.

## 출시 전 반드시 해결할 것

### 1. 주가·환율 데이터 상업용 라이선스

현재 `yahoo-finance2`는 **개발 단계용**으로 생각한다. 유료 앱 출시 전에 상업적 외부 표시 권한이 명확한 데이터 공급자로 교체한다.

검토 후보:

- **Twelve Data Business**
  - 외부 고객에게 데이터를 보여주는 상업용 플랜이 있음.
  - 미국 주식·환율·글로벌 주식 지원.
  - 한국 거래소 데이터도 지원하지만 현재 확인 기준 한국 주식은 EOD 중심.
  - 해외 거래소 데이터를 유료 사용자에게 보여주는 사용 방식은 출시 전 공급자에게 서면 승인/견적 확인.
- **EODHD**
  - 비교적 저렴한 상업용 후보.
  - 고객 대상 표시/재배포는 반드시 사전 서면 허용 범위를 확인한 뒤 사용.
- **KRX / Koscom**
  - 한국 주식 실시간 데이터가 꼭 필요해지면 정식 계약 경로 사용.
  - KRX는 수익사업·재배포 목적 시 별도 계약이 필요하다고 공식 안내.

**출시 기준:** 데이터 공급자로부터 `Stockfolio 유료 앱 사용자 화면에 주가/환율을 표시해도 된다`는 권한을 계약 또는 서면으로 확인하기 전에는 유료 출시하지 않는다.

### 2. 데이터 저장

현재 거래 데이터는 LocalStorage에 있음. 모바일 상용화 전에는 로그인 + 서버 DB로 이전해서 PC/아이폰/안드로이드가 같은 포트폴리오를 보게 만든다.

## 수익모델 방향

기본 방향은 **무료 + 광고 / 유료 = 광고 제거**.

- 무료 사용자: 앱 기능 사용 + 광고 표시
- 유료 사용자: 광고 없음
- 향후 필요하면 유료 사용자에게 추가 분석·백업·고급 기능을 더할 수 있음

### 수수료를 쉽게 생각하면

- **광고 수익:** Apple/Google이 15%를 떼는 구조가 아님. AdMob 같은 광고 플랫폼에서 광고 수익을 받는다.
- **유료 결제:** 사용자가 앱 안에서 광고 제거/구독 같은 디지털 기능을 결제하면 스토어 수수료가 붙는다.
- 사업 계산은 일단 **결제액의 약 15%를 스토어 몫**으로 잡고 시작한다. 실제 출시 시점의 Apple/Google 정책은 다시 확인한다.
- Apple 개발자 등록: 연 $99 수준.
- Google Play 개발자 등록: $25 일회성 수준.

## 광고 수익 계산법

광고는 사용자 수 자체보다 **실제 광고 노출수 × eCPM**으로 결정된다.

`월 광고수익 ≈ 월 광고노출수 ÷ 1,000 × eCPM`

예를 들어 eCPM이 ₩4,000이고 한 달에 광고가 100,000번 실제 노출되면 약 ₩400,000이다. eCPM은 국가, iOS/Android, 광고 위치, 광고 형식, 사용자 품질에 따라 크게 변하므로 실제 앱 출시 후 AdMob 수치를 보고 조정한다.
