# Stockfolio

개인 투자자용 포트폴리오 앱. 웹 완성 → 모바일 앱 → iOS/Android 상용 출시가 목표.

현재 결정과 다음 작업은 [`PROJECT_STATUS.md`](./PROJECT_STATUS.md)를 기준으로 확인한다.

## 제품 방향

Stockfolio는 주식 주문 앱이 아니라 다음 네 축을 연결하는 개인 투자 플랫폼을 목표로 한다.

1. 주식·현금을 포함한 전체 자산과 실제 투자성과 추적
2. 기간별 성과, 벤치마크, 주가·환율·배당 기여도 분석
3. 관심종목의 목표가, 뉴스, 공시와 알림
4. 종목 분석을 근거로 대화하는 종목별 커뮤니티

관심종목·분석·커뮤니티 화면은 현재 제품 구조 검토용 UI이며, 저장·알림·피드 백엔드는 후속 단계에서 구현한다. 화면에 가짜 뉴스나 가짜 커뮤니티 데이터를 표시하지 않는다.

## 로그인과 데이터 저장

- 웹은 **Google 로그인 하나로 시작**한다.
- 별도 Stockfolio 아이디/비밀번호는 만들지 않는다.
- 거래 데이터의 원본은 **Supabase 서버 DB**다.
- LocalStorage는 네트워크 문제 등에 대비한 브라우저 보조 사본으로 유지한다.
- 같은 Google 계정으로 로그인하면 PC/다른 기기에서도 같은 포트폴리오를 불러오는 구조다.
- iOS App Store 출시 시 Google 같은 소셜 로그인을 주 계정 로그인으로 쓰면 Apple 심사 규칙상 동등한 개인정보 보호형 로그인 옵션도 필요할 수 있으므로 **출시 단계에서 Sign in with Apple을 추가**한다.

## 통화 계산 원칙

- 종목 가격은 실제 시장 통화로 저장.
- 포트폴리오는 `₩ KRW` / `$ USD` 중 선택.
- `₩ / $`는 **자산을 어떤 통화 단위로 볼지 정하는 표시 통화 선택**이다.
- 표시 통화 선택과 한국 투자자 관점의 **환차손익 분석 기능은 별도 개념**으로 다룬다.
- **매입원가 = 거래 당시 환율**
- **현재 평가액 = 현재 환율**
- 환차익·환차손까지 선택 통화 기준 손익에 포함.

### 대시보드 자산 및 손익 원칙

- 대시보드의 최상위 값은 `총 자산`이며, 현재는 구현된 자산 종류가 주식뿐이므로 `총 자산 = 투자자산`입니다.
- 투자성과는 투자자산의 평가손익이며, 현금성 자산을 추가하더라도 현금 잔액이 투자성과에 섞이지 않습니다.
- 원화 기준 주식 손익은 `주가 영향 + 환율 영향`으로 분해합니다.
- 외화 주식의 주가 영향은 보유분의 취득 가중평균 환율을 고정해 계산하고, 환율 영향은 그 기준환율과 현재환율의 차이로 계산합니다.
- 국내 주식은 환율 영향이 없으므로 종목 상세 손익에 환율 행을 표시하지 않습니다.

### 향후 현금성 자산 규칙 (저장 기능 미구현)

- KRW, USD 등 현금성 자산의 현재 가치는 항상 현재 환율로 환산합니다.
- 사용자가 외화 현금의 실제 취득환율을 입력하면 그 환율을 환율 손익의 기준으로 사용합니다.
- 취득환율을 생략하면 **현금 등록 순간의 실시간 환율을 한 번 저장**하고 이후 변경하지 않습니다.
- 이 경우 계산 결과는 실제 취득 시점부터의 환차손익이 아니므로 UI에 `등록 시점 환율 기준`이라고 표시합니다.
- 이번 단계에서는 현금 자산의 저장 스키마, 입력 화면, 잔액 관리는 구현하지 않습니다.

## 기간별 성과 계산 원칙

- 성과 기록의 시작점은 과거 거래일이 아니라 사용자가 Stockfolio 포트폴리오를 처음 만든 정확한 시각입니다.
- 사용자가 볼 수 있는 기간은 그 시작일부터 현재까지이며, `전체`를 눌러도 시작일 이전의 빈 과거 구간은 표시하지 않습니다.
- 일별 기록 기준은 매일 `23:59:59 KST`입니다. 과거 날짜는 해당 시점에 확인 가능한 종목별 최근 확정 종가와 환율로 재구성합니다.
- **운용수익률**은 매수·매도에 따른 자금 유입과 유출 영향을 제거해 투자 성과를 비교합니다.
- **내 자금수익률**은 선택 기간에 투입하거나 회수한 금액과 운용 기간을 함께 반영합니다.
- 전부 매도하면 투자자산 그래프는 0원으로 내려가고 미운용 기간의 운용수익률은 마지막 값에서 멈춥니다. 다시 매수하면 그날부터 계산을 이어갑니다.
- 현금 자산 저장 기능이 아직 없으므로 현재의 기간별 자산은 `투자자산`만 의미합니다.
- 비교 자산의 배당 결과는 `배당 포함`, `배당 0원 확인`, `배당 자료 없음`을 서로 다른 상태로 표시합니다.

## 수익모델

기본은 **무료 + 광고 / 유료 = 광고 제거**.

- 무료: 광고 표시
- 유료: 광고 제거
- 추후 유료 기능에 기기간 동기화 / 고급 분석 등을 추가 가능
- 유료결제 계산은 일단 결제액의 약 15%를 스토어 몫으로 잡고 계획
- 광고는 사용자 수보다 `광고 노출수 × eCPM`이 핵심

## 개발 방식

현재는 실제 사용자가 없는 초기 검토 단계이므로 사용자 요청에 따라 **구현 → 로컬 빌드 검증 → main 직접 푸시 → Production에서 확인** 순서로 진행한다. 사용자가 늘거나 운영 데이터의 위험이 커지면 별도 브랜치와 Preview 승인 방식으로 전환한다.
