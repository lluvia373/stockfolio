## 현재 개발 방식

이 프로젝트는 초기에는 Cursor를 이용해 개발했으며, 현재부터는 ChatGPT 대화에서 요구사항을 정하고 연결된 GitHub 저장소를 직접 확인·수정하는 흐름을 기본으로 사용합니다.

기본 작업 흐름은 다음과 같습니다.

1. ChatGPT에서 원하는 기능이나 수정 사항을 자연어로 요청합니다.
2. 필요한 기존 코드를 확인하고 수정합니다.
3. 큰 변경은 별도 브랜치와 Vercel Preview에서 먼저 검증합니다.
4. 검증된 변경을 GitHub `main` 브랜치에 반영합니다.
5. GitHub에 반영된 변경 사항은 연결된 Vercel을 통해 자동 배포됩니다.
6. https://stockfolio-ashen.vercel.app/ 에서 직접 화면을 확인한 뒤 다음 수정 사항을 이어갑니다.

즉, 앞으로는 **요청 → GitHub 수정 → Preview 검증 → main 반영 → Vercel 배포 → 브라우저 확인 → 추가 수정**의 반복을 기본 개발 방식으로 사용합니다.

## 다중 통화 계산 기준

Stockfolio는 서로 다른 통화의 자산을 숫자 그대로 합산하지 않습니다. 사용자는 포트폴리오를 **원화(KRW)** 또는 **달러(USD)** 기준으로 선택해 볼 수 있습니다.

핵심 원칙은 **매입원가는 거래 당시 환율, 현재 평가는 현재 환율**을 사용한다는 것입니다.

예를 들어 삼성전자를 ₩1,000,000어치 샀을 때 거래일 환율이 `$1 = ₩1,250`이었다면 달러 기준 매입원가는 `$800`입니다. 이후 삼성전자 평가액이 ₩1,100,000으로 올라도 현재 환율이 `$1 = ₩1,400`이면 달러 현재가치는 약 `$785.71`입니다. 따라서 원화 기준으로는 수익이어도 달러 기준으로는 환율 변화를 포함해 손실일 수 있습니다.

반대로 미국 주식을 원화로 볼 때도 매수 당시 USD/KRW와 현재 USD/KRW를 각각 사용하므로 원화 기준 손익에 환차손익이 포함됩니다.

표시 통화를 바꾸면 다음 항목이 함께 전환됩니다.

- 총 평가액
- 총 매입금액
- 총 손익
- 수익률
- 보유 종목 평가액 및 손익
- 자산 배분

종목의 원래 시장 가격은 현지 통화로 함께 확인할 수 있습니다.

## 주요 기능

- **대시보드** — 총 평가액, 손익, 수익률 확인
- **포트폴리오 관리** — 종목 추가/삭제, 보유 수량 및 평균 매입가 추적
- **거래 기록** — 매수·매도 거래와 과거 거래일 기록
- **종목 검색** — 티커 또는 회사명으로 주식 검색
- **종목 상세** — 현재가, 시가총액, 52주 고저가, 가격 차트
- **자산 배분** — 포트폴리오 구성 비율 시각화
- **표시 통화 전환** — 전체 포트폴리오를 KRW 또는 USD 기준으로 전환

- Next.js 16 (App Router)
- TypeScript

## 로컬 실행

```bash
npm install
npm run dev
```

실행 후 브라우저에서 http://localhost:3000 을 열어 확인합니다.

## 사용 방법

1. **거래 기록** 페이지에서 종목을 검색합니다. 예: `AAPL`, `TSLA`, `005930.KS`
2. 거래일, 매수·매도, 수량, 거래 가격을 입력합니다.
3. 상단 `₩ / $` 버튼으로 원하는 포트폴리오 표시 통화를 선택합니다.
4. **대시보드**에서 선택한 통화 기준 전체 포트폴리오 현황을 확인합니다.
5. **포트폴리오**에서 보유 종목과 거래 내역을 확인합니다.
6. 종목명을 클릭하면 **상세 페이지**에서 차트와 추가 정보를 확인합니다.

## 지원 종목

Yahoo Finance 데이터를 통해 여러 시장의 종목을 조회합니다.

- 미국: `AAPL`, `MSFT`, `GOOGL` 등
- 한국: `005930.KS`, `000660.KS` 등

## 데이터 저장

현재 포트폴리오 데이터는 브라우저 LocalStorage에 저장됩니다. 따라서 사용하는 브라우저와 기기에 따라 저장 내용이 달라질 수 있습니다.
